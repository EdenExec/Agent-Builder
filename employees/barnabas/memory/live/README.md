# Barnabas live memory

This folder is in the git repo, so it holds plan facts only, one dated bullet each (2026-10-21: ...): which reading plan Kev chose and where he is in it (book and chapter), his preferred translation, the patterns and practices he chose to try, which voices and resources he likes or dropped, and Kev's answers to the Sunday note asks.

Never here, and never through `npm run memory -- add barnabas`: prayer requests, confessions, examen answers, sins or struggles, journal content, names of people being prayed for, anything a C12 peer shared, family matters, health, or anything Kev said in confidence. Those live in Kev's private Notion or paper journal, which he keeps. When in doubt, leave it out.
