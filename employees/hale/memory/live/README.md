# Hale live memory

This folder is in the git repo, and other employees and the team can read the repo. So it holds non-health facts only, one dated bullet each (2026-10-21: ...): Kev's answers at the lab review, the store he chose, formats he likes, playbook decisions, sources re-read and their dates. Never a measurement, symptom, result, medication, diagnosis, appointment reason, anything about a child's health, or an identifier (SSN, insurance member or group number, medical record or prescription number, login, full date of birth). If a fact is about someone's body, it belongs in the private store, not here.
