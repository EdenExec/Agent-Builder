The working loop

You steer at two points. The employee does the rest.

Every employee in the workshop follows the same loop, so the second hire costs a fraction of the first.

You

Brainstorm

Talk through the site, family, budget, taste. The agent asks sharp questions and pushes back.

Agent

Write the brief

Turns the chat into a one-page design brief with open assumptions listed. You edit and approve it.

Agent, away

Work

Searches licensed image sources, curates boards, runs the planning math, builds the massing model.

Agent

Self-review

Scores its own output against a rubric for that deliverable and fixes what fails before you see it.

You

Review

Pin, reject, comment. Your reactions are saved to the employee's memory and shape the next round.

How the employee is built

Five parts, all plain files you can read and edit.

Everything lives in employees/housing-architect/. A new hire is a new folder.

agent.yaml

Role and rules

Who they are, what they may do on their own, what needs your sign-off, spending and time limits.

skills/

Playbooks

Brainstorm interview, board curation, programme and zoning study, massing generation, design critique.

memory/

What they remember

Your taste, past projects, rejected tiles, site facts. Seeded with architecture and planning fundamentals.

rubrics/

Definition of good

Checklists the agent scores its own work against, and that I use to test it before handing it over.

evals/

Probation tests

Sample briefs with known good outcomes. If a change makes the employee worse, the suite catches it.

tools

Hands

Image search across four licensed sources (built), board builder, massing engine, file export.

Forecast

What I expect to go wrong.

Ranked by how likely it is to hurt. Each has a planned defence.

RiskLikelihoodWhat happensDefence
Photoreal rendersHighNo image generation model is wired in. A browser 3D view looks like a clean study model, not a magazine render.Ship clean massing first. Add a render step only if you give me an image generation key. Tell me which you want.
Zoning is localHighSetbacks, height and coverage differ by city. A guess presented as fact is dangerous.Agent asks for your jurisdiction, takes rules as inputs, labels anything unverified, and never calls a design compliant.
Taste driftMediumBoards look generic, or keep repeating the same look after you reject it.Reject reasons stored in memory, diversity rule per board, a taste summary you can edit.
Image licensingMediumA source changes terms or a file is mislabelled. Unsplash and Pexels need attribution.Licence stored per tile, NC and ND dropped, attribution printed on every export.
Image links rotMediumBoards break when a source URL dies.Boards embed the image bytes. Already in the design.
Agent overreachMediumIt runs long, spends too much, or acts on its own assumptions.Hard limits in agent.yaml, assumptions listed in every brief, you approve the brief before work starts.
Geometry bugsMediumOdd lots, slivers and non-rectangular sites produce broken or overlapping volumes.Geometry tests on awkward polygons, plus a validity check before any model is shown.
Phone useLow3D viewer is heavy on older phones.Light meshes, tap-to-orbit, static fallback images.
Your markup

Questions before I build Phase 1.

Each has my default. Reply with just the ones you want to change, and add anything I have not thought of.

1. Where do these projects sit?

Country and city, or "varies by project". This decides the zoning approach.

Default: rules entered per project, none assumed

2. What does "3D rendering" mean to you?

  • Clean massing model you can orbit
  • Stylised images of that model
  • Photoreal interiors and exteriors
Default: massing now, renders only with an image key

3. Who is a project for?

Your own builds, clients, or both? Clients mean shareable boards and a cleaner export.

Default: both, export-first boards

4. Scale and type of housing

Single homes, townhouses, small multifamily, subdivisions? This sets how deep the master planning goes.

Default: single home to small multifamily

5. Where should the work live?

  • Files in this repo
  • A web page you open on your phone
  • Both
Default: files first, browser office in Phase 5

6. What should it do without asking?

Examples: spend image API quota, start a new board, revise a brief, re-run a study overnight.

Default: boards and studies free, brief changes need approval

7. Features you already want

Ideas I would add if you agree: mood to materials palette, room-by-room programme, budget estimate ranges, site photo markup, before and after comparisons, a style quiz for clients.

Tick any, strike any, add your own
