## Executive summary

*How to use; comes off the signed copy.*

- **One SOW per Site;** no blank fields. The Site state sets governing law, the safety program and the Florida indemnity limit.
- **Describe real duties,** not titles: they set the workers' comp class code and which Prohibited Duties are authorised.
- **Name one supervisor and one Approver.** Every change goes through a signed change order (Section 7).
