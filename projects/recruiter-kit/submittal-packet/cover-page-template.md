## Google search link: the Boolean

Name variations AND location (Kev, 24 Oct 2026). Location is the candidate's current state plus every state where they lived or worked before, from the resume.

Pattern:

`("First Last" OR "First M Last" OR "Nick Last" OR "Last, First") AND ("State1" OR "State2" OR "State3")`

Link: `https://www.google.com/search?q=` followed by the pattern, URL-encoded.

| Variation to include | Example (made up) |
|---|---|
| Formal first name | "Michael Smith" |
| Nickname | "Mike Smith" |
| Middle name or initial | "Michael J Smith" |
| Reversed | "Smith, Michael" |
| Maiden or former surname, if the candidate offers one | |
| States | Current state first, then each earlier state, spelled out |

Rules: public search only. One link on the page, labelled "First-pass search". Do not paste results onto the page.
