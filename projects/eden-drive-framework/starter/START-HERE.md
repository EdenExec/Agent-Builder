# Start here: your Eden agent folder

This folder is yours, and it lives in the Eden Google Drive, so your work stays with Eden.

1. Copy the "03 Templates/my-folder" files into "01 People/<your first name>".
2. Install Google Drive for desktop and make sure your folder is available offline on your computer.
3. Open the Claude desktop app, Code tab (or a Cowork project), and pick your folder.
4. Say: "Read RULES.md and 00 Shared/README.md, then help me set up my first playbook."
5. Run anything by hand a couple of times before you put it on a schedule.

Rules: no pay, health or family details in any file. Nothing goes to a client or candidate until Kev has reviewed it.
