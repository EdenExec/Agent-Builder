# Must Dos intake template

One per JO, completed on the intake call and filed with the JO. Every JO from now on gets one (Kev, 24 Oct 2026). 7 to 10 core elements of the job.

| Field | Fill in |
|---|---|
| Client / JO / role | |
| Lead recruiter / date of intake call | |
| Source of the list | Client gave it on the call, or Eden built it (then sent for approval) |
| Approval | Client name and date approved. Not approved means no scorecard |

## Questions to ask on the call

| # | Question |
|---|---|
| 1 | What are the 7 to 10 things this person must have done or must be, or they will not work out? |
| 2 | Which project types, sizes and delivery methods count? |
| 3 | Which scopes or systems must they have run themselves? |
| 4 | Licences, certifications, clearances? |
| 5 | Location, travel and start-date limits? |
| 6 | Team size and level they must have led? |
| 7 | What did the last person get wrong, or the one you wish you had hired? |
| 8 | What would make you stop the interview? |
