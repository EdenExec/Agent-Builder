Eden Partner Group · for the recruiting team

Your recruiting assistant

Your own Claude, connected to Crelate, that builds Eden submittal packets the way we do them. Use your Eden Claude login (your edenexec.com email), never a personal account. Screen someone, tell it who and for which job, and it hands you a packet to review. It never sends anything: you review, Kev reviews, you send.

Step 1 · everyone · 2 minutes

Turn on your Crelate API key

Keep the key to yourself. Never paste it into a chat, an email or a doc. If you ever do by mistake, turn API Access off and on again to get a new one.

Step 2 · pick where your assistant lives

Choose A or B

Both give you the same recruiting assistant and the same rules. Pick the one that fits how you work; you can switch later.

Option A · cloud · free GitHub account

Runs in the cloud, even with your laptop closed

  1. 1
    Make a free GitHub account at github.com/signup with your edenexec.com email. Send Kev or Nick your username; they add you to EdenExec/recruiter-kit.
  2. 2
    Open Claude Code at claude.ai/code, signed in with your Eden Claude account. Connect GitHub when it asks. Start a session on EdenExec/recruiter-kit.
  3. 3
    Save your key in settings. Title bar → cloud environment menu → Edit → Network secrets (or Environment variables): name CRELATE_API_KEY, value your key.
  4. 4
    Let it reach Crelate. Same screen, Network access: add app.crelate.com to Allowed domains, leave "Allow package managers" ticked, save.
Option B · on your computer · no GitHub

Runs in the Claude desktop app while your laptop is open

  1. 1
    Install the Claude desktop app from claude.ai/download and sign in with your Eden Claude account. The recruiting assistant is already there as an Eden skill (eden-recruiting-assistant).
  2. 2
    Make a work folder, for example Eden Submittals in your Google Drive folder. Open the desktop app's Code tab and choose that folder.
  3. 3
    Save your key on your computer, not in a chat. Open the file .claude/settings.json in your home folder (Mac: ~/.claude/settings.json, Windows: %USERPROFILE%\.claude\settings.json; create it if it isn't there) in any text editor, add the lines below with your key, and save. Claude can tell you where the file is; you type the key yourself.
    {
  "env": { "CRELATE_API_KEY": "paste-your-key-here" }
}
  4. 4
    Restart the desktop app so it picks up the key.

Coming soon, maybe the easiest of all: Crelate now has its own AI / MCP Access page (beta, right under API Access). It may let Claude connect to Crelate with a Connect button instead of a key. Q is testing it, read-only, before anyone turns it on. Don't connect it yourself yet.

Step 3 · test it

Check the connection

Start a new session (A) or a new chat in the Code tab (B) and paste the first prompt below with a candidate you know. If the record comes back, you're connected. "Blocked" means Crelate isn't allowed yet (A, step 4). "Key missing" means the key isn't saved, or the session or app started before you saved it.

The deal

How we use it

  • Nothing leaves without your yes. Claude drafts; you and Kev review; you send. No emails, uploads to client portals, posts or spending, ZoomInfo credits included.
  • Crelate is read-only for Claude. Stage moves, notes and tags are yours to do in Crelate.
  • Your key, your account. Never share your key, never paste it into a chat, and keep Eden work in your Eden Claude, never a personal account.
  • Desired pay only on a cover page, and no made-up facts: if it isn't in the resume or your notes, it says "confirm with candidate".
  • Discreet clients show as "Client · discreet". No thumbs-up/down feedback on chats with candidate or client details.
